service remained untouched. It received 500 round-robin requests from 10
concurrent clients after one warm request per URL. The request family covered:

- noun suggestions for `情報`;

maximum 1,092.335 ms, and 16.276 seconds wall time. This passes the p95 below
one second and 100% success criteria on the named host.

### Matched follow-up

The original benchmark remains valid release evidence, but it compared a new
three-corpus workload with the earlier two-corpus release and therefore was not a
complexity measurement. A follow-up on the same `kurent` host separated artifact growth
from corpus selection. Direct servers for the immutable 2026-08-13 and 2026-08-14
artifacts ran on ports 18010 and 18011. Each observation warmed all six URLs, then sent
500 round-robin requests. Four observations per case were collected in balanced
`old2, new2, new3, new3, new2, old2` order at concurrency 1 and 10; all 12,000 measured
requests returned HTTP 200.

The harness is reproducible with:

```bash
nix develop .#test --command python -m natsume_simple.benchmark_service \
  --base-url http://127.0.0.1:18011 \
  --corpus-id jnlp --corpus-id wiki --corpus-id ted \
  --requests 500 --concurrency 10 \
  --output /tmp/natsume-benchmark.json
```

At concurrency 1, changing only the artifact moved aggregate p95 by 1%, while selecting
TED on the new artifact added 10%. At concurrency 10, the old2/new2 difference was
within run variation, while selecting TED added 35% to aggregate p95. Concurrency and
queueing were the largest measured effect; selecting a third corpus was the next clear
effect. These results do not support attributing the earlier threefold aggregate change
to data growth alone, so no query optimization follows from this measurement.

Re-run the matched diagnostic before adding another corpus, when a fixed matched case
reaches p95 >= 600 ms, or when any measured maximum exceeds 2,000 ms. The prior
1,092.335 ms maximum remains recorded as part of the original mixed release pass; no
fixed matched case crossed either investigation threshold.
